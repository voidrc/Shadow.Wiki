Linux is a powerful system, it is mostly command line based. So, we need to learn how to use it.

Command is an instruction given by user telling computer what to do. This could be to run single command or a group of linked commands and programs. Commands are typically initiated by user typing them in terminal and then passed to shell by pressing "Enter" key.

Terminal refers to a wrapper program that allows user to interact with shell. It provides a graphical interface for user to type commands and see output.

Shell is a program that interprets and executes commands. It is the interface between user and kernel. It is the program that runs commands and returns output. Every Linux distribution has atleast one shell, but can have multiple shells installed. Default shell is usually bash.
